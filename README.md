# Scoreboard Remote Sim (web)

Practice simulator for a water polo scoreboard remote control, playable in any browser and installable as an app
(works offline). Open it at https://flungabunga.github.io/aussport-remote-sim/ — on iPhone use Safari › Share › Add to
Home Screen; on Android or desktop Chrome use "Install app".

This is a web port of the Scoreboard Remote Control Simulator v10.3, developed by Robert Allan for the UNSW Wests
